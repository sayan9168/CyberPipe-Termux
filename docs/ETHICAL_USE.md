# Ethical Use Guidelines for CyberPipe-Termux

## You MUST:

1. Only test systems you **own** or have **explicit written authorization** to test.
2. Respect the scope defined in any penetration testing agreement.
3. Stop immediately if you discover you are testing the wrong target.
4. Report findings responsibly through proper channels.
5. Never use these tools for illegal activities, harassment, or unauthorized access.

## Legal Note (India)

Under the Information Technology Act, 2000 (as amended), unauthorized access to computer systems is a criminal offense. Similar laws exist in almost every country.

## Recommended Practice

- Always get a signed Rules of Engagement (RoE) document.
- Keep detailed logs of your testing activities.
- Use this tool for learning, CTFs, bug bounty programs (within scope), and authorized red team exercises only.

**If you are unsure whether you have permission — DO NOT PROCEED.**
